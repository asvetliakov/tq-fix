# Seeds for the Engine.dll resource / region-streaming call-graph closure.
#
# Every name below was selected from the 5599 exported symbols of the supported
# Engine.dll, not guessed; research/streaming/exports.md records the filtering
# and the per-family counts.
#
# ExportShadowAudit.java matches a seed as a plain substring of the function's
# display name, so each class-qualified entry is listed twice: once in Ghidra's
# demangled `Class::Method` spelling and once as the `Method@Class` substring of
# the MSVC-mangled label that survives when the demangler declines a symbol.
# Bare method names that are already unique across the export table are listed
# once.
